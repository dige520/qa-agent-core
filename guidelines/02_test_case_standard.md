# 测试用例生成与质量门禁规范

## 1. 前置范围闸门声明 (Scope Gate)

在调用 Agent 生成测试用例前，必须明确：
1. **测试对象与版本**：明确被测系统、版本号；
2. **测试阶段**：P0 冒烟 / P1 专项 / 集成回归；
3. **范围划分**：必须明确包含项（Included）与排除项（Excluded），防止无故扩大测试范围。

## 2. 覆盖矩阵与深度维度

必须覆盖但不限于以下维度：
- 核心正向业务流程（Must）
- 异常断网、超时与依赖降级（Must）
- 边界极限值与极端并发（Must）
- 历史缺陷防回归断言（Must）

## 3. 用例输出质量验收标准 (DoD)

- 每个用例必须有清晰确定的 `case_id` 和优先级（P0/P1/P2）；
- 断言必须具体可自动化执行（如明确校验日志关键字、返回状态码、字段键值），严禁使用“表现正常”等模糊描述。
